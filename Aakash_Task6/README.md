
# Laundry Mart Login Page

## Files
- index.html
- index.css

## Technologies
- HTML
- CSS Flexbox

## Features
- Login form
- Email and password inputs
- Login button
- Forgot Password link
- Register Now link

## How to Run
1. Save index.html and index.css in the same folder.
2. Open index.html in your browser.
3. The login page will appear.
