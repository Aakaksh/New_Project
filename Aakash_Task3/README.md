# HTML and CSS Styling Practice

## 📌 Project Overview

This project demonstrates the basic concepts of HTML and CSS by creating a simple webpage with different heading tags, paragraphs, lists, and hyperlinks. It focuses on using CSS selectors to apply colors, backgrounds, font sizes, and other styling properties.

## 🎯 Objectives

- Create a webpage using HTML5.
- Connect an external CSS stylesheet to HTML.
- Apply styles using element, class, and ID selectors.
- Customize heading and paragraph styles.
- Style hyperlinks without using inline CSS or assigning classes and IDs to anchor tags.
- Use pseudo-classes to style specific list items.

## 🛠️ Technologies Used

- **HTML5:** To structure the webpage.
- **CSS3:** To style webpage elements.

## 📂 Project Structure

```text
HTML-CSS-Project/
│
├── index.html

└── README.md
```

## ✨ Features

1. Three different heading tags: `h1`, `h2`, and `h3`.
2. Class-based styling using the `.head` selector.
3. Background color customization using the `#bglime` ID selector.
4. Paragraph styling using element, class, and ID selectors.
5. Different text colors and font sizes.
6. Hyperlink styling using descendant selectors.
7. Ordered and unordered lists with customized styling.
8. List item styling using the `:nth-child()` pseudo-class.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Ensure that `index.html` and `style.css` are in the same directory.
4. Open `index.html` in your web browser.
5. Observe the webpage and its CSS styling.

## 📚 CSS Concepts Demonstrated

| CSS Concept           | Example                    |
| --------------------- | -------------------------- |
| Element selector      | `p { }`                    |
| Class selector        | `.head { }`                |
| ID selector           | `#bglime { }`              |
| Descendant selector   | `ul li a { }`              |
| Pseudo-class selector | `li:nth-child(1) { }`      |
| Background color      | `background-color: coral;` |
| Text color            | `color: darkblue;`         |
| Font size             | `font-size: 18px;`         |

## 🎓 Learning Outcomes

After completing this project, learners will understand how to structure a webpage using HTML, connect an external stylesheet, apply different CSS selectors, control text and background colors, and style lists and hyperlinks.
