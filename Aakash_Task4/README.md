
# Image Display Webpage

## Aim
To create a webpage using HTML and CSS that displays an image with a gradient background button.

## Technologies Used
- HTML
- CSS

## Files Included
- `index.html` – Defines the structure of the webpage.
- `style.css` – Provides styling and layout.
- `image.jpg` – Image displayed on the webpage.

## Features
- Displays an image inside a container.
- Adds a Click Me button below the image.
- Uses a gradient background for the button.
- Applies equal left and right spacing using viewport units.
- Uses CSS box-sizing for proper dimension control.
- Does not use Flexbox, media queries, or absolute positioning.

## How to Run
1. Place all files in the same folder.
2. Ensure the image file is named `image.jpg`.
3. Open `index.html` in any web browser.
4. View the image and click the button.

## Expected Output
A webpage displaying a landscape image with a yellow-to-green gradient button underneath it.

## Conclusion
The webpage demonstrates basic HTML structure, external CSS styling, viewport units, image display, and button design.
