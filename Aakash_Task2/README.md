# Laundry Wallah / Laundry Mart

A simple and user-friendly laundry service website built using HTML. The website provides information about laundry services, pricing, and a booking form for customers.

## 📌 Project Overview

Laundry Wallah / Laundry Mart is a basic web development project designed to showcase a laundry service business online. It helps customers explore available services, view prices, and submit their contact details through a booking form.

## ✨ Features

- **Welcome Section:** Displays the website title and welcomes visitors.
- **About Us:** Introduces the laundry business and its services.
- **Laundry Image:** Displays an image related to laundry services.
- **Our Services:** Lists the laundry services offered.
- **Price List:** Shows service names and their prices in a table.
- **Booking Form:** Allows customers to enter their name, email address, and phone number.
- **Contact Information:** Provides an email address for customer inquiries.

## 🧺 Services Offered

- Washing and Drying
- Ironing and Folding

- Stain Removal

## 🛠️ Technologies Used

- **HTML5** – Structures the website content.
- **HTML Forms** – Collects customer booking information.

- **Semantic HTML** – Organizes the page into header, sections, articles, and footer.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Ensure that `index.html` and the laundry image are in the correct locations.
4. Open `index.html` in your web browser.
5. Explore the services, price list, booking form, and contact information.

You can also use the **Live Server** extension in Visual Studio Code to run the website locally.

## 📋 Booking Form

The booking form includes the following fields:

- Name
- Email
- Phone Number

The form uses HTML validation through required fields and the email input type.

**Note:** The current form is a front-end implementation. It does not store customer information or send bookings to a server. Backend functionality would be required to process bookings.
